## 📌 Overview

**Disaster Command Center** is a centralized web dashboard designed for rapid response and efficient monitoring during high-pressure emergency situations (such as floods, earthquakes, and fires).

By consolidating incident tracking, location mapping, and rescue resource management into a single control panel, this application helps response teams make fast, data-driven decisions when every second counts.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| ⚡ **Real-Time Incident Tracking** | Monitor active emergencies, critical alerts, and high-priority incidents in real time. |
| 🗺️ **Interactive Mapping** | Visual analytics for affected zones, high-risk areas, and safe evacuation routes. |
| 🚑 **Resource Allocation** | Track live availability and deployment status of emergency personnel and medical supplies. |
| 📊 **Data & Analytics** | Visual stats and metrics to support tactical decision-making. |
| 📱 **Fully Responsive UI** | Optimized for seamless viewing across mobile, tablet, and desktop devices. |

## 🚀 Local Setup & Installation

Follow these steps to set up and run the project locally on your system:

### 1. Clone the Repository
```bash
git clone [https://github.com/haninayi24cse-hue/Disaster-command-center.git](https://github.com/haninayi24cse-hue/Disaster-command-center.git)

```

### 2. Navigate to the Directory

```bash
cd Disaster-command-center

```

### 3. Install Dependencies

```bash
npm install

```

### 4. Start the Development Server

```bash
npm start
# or
npm run dev

```

Open `http://localhost:3000` in your browser to view the application.
